# Book Market – Web Application

Book Market is a simple and responsive web application built using **HTML, CSS, and JavaScript**.  
Its main purpose is to simulate a basic online bookstore with search, filtering, cart, and favourites features.

---

## Features

### Search System
- Search for books by name.
- Filter books by category.

### Cart Page
- Add and remove books from the cart.
- Data stored using LocalStorage.

### Favourite Page
- Save favourite books.
- View and remove items.

### Authentication (Front-End)
- Login Page
- Sign Up Page  
*(Data handled locally for demo only)*

---

## 🧰 Technologies Used
- **HTML5**
- **CSS3**
- **JavaScript (ES6)**  
- LocalStorage
